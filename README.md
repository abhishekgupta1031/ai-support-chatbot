# 🤖 AI-Powered Customer Support Chatbot

An intelligent AI-powered customer support chatbot built with **Python, Flask, NLP, TF-IDF, SQLite, and NLTK**.

The chatbot can understand customer queries, identify user intent, answer FAQs, maintain basic conversation context, recognize order IDs, and provide a professional web-based chat interface.

## 🚀 Live Demo

**Live Application:**  
https://ai-support-chatbot-qymo.onrender.com

## ✨ Features

- 🤖 AI-powered customer support chatbot
- 🧠 NLP-based intent detection
- 🔎 TF-IDF and cosine similarity matching
- 💬 FAQ-based responses
- 📦 Order ID detection
- 🔄 Conversation context handling
- 💳 Payment-related query handling
- 🚚 Order status and delivery queries
- 💰 Refund and cancellation support
- 📊 Confidence score and smart fallback responses
- 📝 Chat interaction logging
- 🗄️ SQLite database
- 👨‍💼 Secure admin dashboard
- 🔐 Environment-variable based admin authentication
- 📈 Chat analytics and charts
- ➕ Admin FAQ management
- 🗑️ Admin FAQ deletion
- ⌨️ Typing/loading animation
- 📱 Responsive professional UI
- 🚀 Deployment with Render
